# Read-only learning web

## Context

The owner deferred every runner-backed action and selected a lightweight Vietnamese reader over an
interactive execution product.

## What changed

- One build-time loader now binds the portal directly to released curriculum, architecture, lab,
  and promotion-trust authorities with exact hashes and structural invariants.
- React and the static renderer publish the same bounded 38-route information architecture.
- Manual commands remain semantic text; the browser owns no mutation, storage, network, or
  completion capability.

## Decisions

- Keep no-JavaScript parity as a release invariant, not a fallback.
- Treat architecture SVG and text alternatives as hash-bound source artifacts.
- Keep Stage B fail-closed and explicitly owner-deferred.
