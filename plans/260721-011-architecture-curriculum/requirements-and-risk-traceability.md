## Risk Register

| Risk | Failure mode | Mitigation / stop |
|---|---|---|
| Wrong lineage | Failed feature bytes enter v4 | Direct integration ancestry and plan-only diff; forbid `c07c9a0…` |
| False RED | Expected-code dictionary or fake state drives result | Real repository copies, stripped metadata, callable plus public route |
| Runtime drift | Mixed venv/root/PATH or missing tools | One literal runtime shape, closed env, exact hashes, fail closed |
| Template rot | Copies/unknown successors/orphans bypass registry | Exact discovery/registry/instance set equality and lifecycle mutations |
| Render theater | Hardcoded cards/hashes hide source relation drift | Locked sole-source chain and visible DOM/text mutation gate |
| Curriculum duplication | 20 renamed clones satisfy count | Unique learning signatures and meaningful body checks |
| Governance mismatch | Progress path substituted for adapters topology | Exact protected relation and `adapters_instance` reciprocal proof |
| Evidence fiction | Raw bytes deleted or cook called independent | Raw retention, separate sanitized logs, truthful roles/bundles |
| Resource escape | Descendant survives deadline | Owned PGID, sampling, TERM→KILL→wait, zero descendants |
| Scope creep | Stage B/cloud/docs/shared changes enter Stage A | Exact 50/16 sets, empty Stage B authority, hard stop |
